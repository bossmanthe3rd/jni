# CLAUDE.md

## Design skills

For any UI, styling, layout, component, animation or copy work in this repo,
load both project skills with the Skill tool before starting:

- `frontend-design`
- `web-design-engineer`

Apply them in proportion to the task: run the full web-design-engineer process
(design read, system declaration, v0 checkpoint) for new sections and
redesigns; for small tweaks (spacing, a colour fix, a copy edit), follow the
principles but skip the confirmation checkpoints.

Skip them for non-visual work (build/tooling fixes, Python scripts in `tools/`,
git housekeeping).
